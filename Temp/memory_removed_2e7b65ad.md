## Memory Block

**工作背景**
用户聚焦能源大宗商品数据分析与全球炼油产业追踪，同时深入美国股票市场板块相关性研究与期权策略分析。能源端核心数据源为周度 EIA 石油数据（系列 WGFUPUS2 产品供应、WGFRPUS2 生产量）以及 NYMEX RBOB 汽油期货与燃料油期货周度 OHLC K 线数据，分析维度覆盖 HO 燃料油出口、馏分油、车用汽油产能与供需平衡，按年份对比当期与历史均值（季节性分析排除疫情影响年份 2020-2022），同时管理一个美国能源数据项目（EIA 原油库存、油价、成品油贸易），含自动化每日 22:00 任务抓取 AAA 全美平均油价至 xls，并通过新浪（finance.sina.cn）实时跟踪霍尔木兹海峡通航情况以交叉验证 EIA 出口数据，同时研究全球10年期国债收益率走势及其对长久期资产（高估值成长股/AI/biotech）利率敏感性的宏观传导逻辑，在宏观分析后倾向追问概念辨析（如长端 vs 短端走强区别）。全球炼油产业侧重点关注乌克兰对俄罗斯炼厂袭击事件、裂解价差波动及其对汽油（而非柴油或军工）供给侧的传导；裂解价差及能源/炼油资讯通过 Twitter/X 跟踪，关注高质量推文筛选及评论联动审阅；同步开展美国原油库存公式研究（产量+净进口-加工量-SPR）以校验 EIA WPSR 估算精度，并深入分析汽油/馏分油期货价格行为及潜在短期操纵可能性，同时实时跟踪美股资产管理板块基本面驱动（APO/KKR/BX/OWL/TPG）。股票端聚焦美股板块相关性分析（VST/XLU/QQQ/SOXX/XLK/XLV/CSCO 等）与 AI 电力主题（Vistra），同时深入研究 IBB ETF 与其前十大成分股（AMGN、VRTX、GILD、REGN、ARGX、LEGN、ALNY 等生物医药板块）的相关性及超额收益结构——当前以 2026-02 为结构断裂点开展分阶段相关性拆解，产出含表格式数值对比与成分股级拆解贡献；同时将 IPP（独立发电商）主题纳入研究视野，涵盖 VST/Vistra、UTES ETF，重点关注 CEG/VST/TLN/NRG 等 IPP 个股以及 XEL/CNP/ETR/LNT/SRE/NEE 等传统受管制公用事业，开展分阶段相关性研究；通过 IBKR 盈透证券账户实操美股交易，下载 1h/4h/日线三周期 MACD 数据辅助决策；当前持有 NVDA 260918 210C 主动期权头寸；Twitter/X 上优先用英文关键词搜索，偏好 curated 高价值推文（非原始 dump）并附评论要点摘要，用于个股情绪（VST、GILD 等）辅助判断；明确 MACD 信号定义（日线水下金叉 + DIF 上穿 0 轴 + 4h 走弱未死叉 + 1h 水下转强），入场偏好从 4h 走弱日（E）起算而非日线确认日（D），通常提前 0-3 天，并以价格持续站上 EMA10/EMA20 作为金叉后的可靠性确认信号；同时研究多周期 MACD 三周期（1 小时/4 小时/日线）共振与反转信号体系，并聚焦 GILD 财报事件对 IBB/XBI/XLV 及 VIX 对医疗/生物科技板块的传导；IQVIA 作为生物医药板块额外成分纳入视野；生命科学工具板块（IHI、A/WAT/DHR、TMO）亦在研究视野内，对应 IHI ETF 与 A/DHR/TMO 等龙头。正在构建一个多腿组合 Bull Call Spread 期权策略（标的疑似 OG，行权价 4400/4600）的 HTML P/L 曲线工具，集成 Black-Scholes 定价与日期滑块分析，用户对期权希腊字母（gamma 影响曲线斜率如 bull spread 接近较高行权价时趋缓，theta 推动曲线向到期日演化）有深入理解，能够以量化+基本面结合方式识别反向案例与极端日成因。所有浏览器相关抓取一律通过本机 Chrome + CDP 完成（环境为 Windows host，Python 工具链位于 `.workbuddy/binaries/python/`，长记忆工作区 `.workbuddy/memory/`），不走 agent-browser 或无头 Chromium，并附带 SSR 渲染截图核查；WorkBuddy 项目用于沉淀自定义 skill 体系（含 `回测明算` 量化回测专家角色）、实现跨 session 上下文持久化，并管理自有 GitHub 仓库 alberthuang422/stock（stock/biotech 研究 repo，含 reports/ 编号体系，目前产出至 23-49+ 号）。

**个人背景**
用户偏好以结构化、严谨的方式进行研究与产出，输出语言为中文（简体），UI 文本亦统一中文，偏好研报风格 HTML 格式输出（多层级分析+数据）。能源端交付物为自包含 HTML 报告，内嵌 SVG 折线图（Okabe-Ito 色板）、年份复选框交互、tooltip 按数值从大到小排序；首个图表样式在成功后复用至后续数据集。期权工具 UI 全中文呈现，用户以短反馈循环迭代，逐项指出 UI/视觉缺陷并要求 AI 分析根本原因（非仅打补丁），聚焦多腿组合、定价模型与日期滑块三类核心功能。股票端偏好分阶段、对比式结构化分析框架（如按特定日期分界点拆解相关性、超额收益需覆盖分界前/分界后/今年以来等多时间段），结论先行，避免冗长铺垫，常在初步结论后追问反向案例、极端日成因、跨板块对比、跷跷板效应、相对强度比率、阶段性超额收益等以深化判断；典型应用包括美股板块跨周期 MACD 三周期共振与反转分析、IPP/受管制公用事业分阶段相关性拆解，以及 IBB 与生物医药成分股的分阶段相关性/收益率/超额收益拆解（相对强势占比、阶段超额等），并对 MACD 信号定义及股票相关性方法选择进行迭代式验证与重统计——根据反例不断调整参数（信号边界、样本量、命中率），要求用新参数重跑统计支撑结论修正；同时主动指出报告覆盖缺口（如分界前超额收益缺失）并要求补全。所有结论必须来自 Reuters/Bloomberg/BBC 等权威信源，严禁 AI 编造；面对结论时倾向反复质询统计方法、样本量与定义边界，要求图表验证与具体案例，并要求跨源交叉验证，在反证出现时主动要求更新/修正先前论断。回复偏好含详尽表格、百分比、明确数字证据与可视化图表，避免笼统叙述；论述要求多角度框架（价格、库存、贸易流、供需缺口等），强调数据纪律——在证据缺失时优先说"未找到"而非猜测，当用户假设存疑时基于证据予以纠正，并偏好按时间段/分窗口拆解相关性等分析方法。属于善于发散追问的研究型用户，常从相关性出发逐步深入到个股、商业模式、估值、行业机制（如电力市场机制、利率传导、资产管理公司商业模式、biotech 药物管线机制）等层面，并要求 follow-up 分析逐层下钻至贡献拆解与成分股级解构。
