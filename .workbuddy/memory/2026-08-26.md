## VIX 低位 × SPY 事件研究（新报告，SPY 口径）
- 背景：旧报告 `vix_low_spx_report.html` 是 GSPC 指数口径（1990 起）；用户要 VIX 低位的持有时长 + SPY 表现，本次改用 **SPY ETF（1995-01 起，7961 交易日对齐）**。
- 产出：`reports/vix_low_spy_dashboard/index.html`（skill 模板渲染）+ `results/vix_low_spy.json` + `results/vix_low_spy_events.csv`（2395 事件日）+ 脚本 `scripts/vix_low_spy.py`、`scripts/build_vix_low_spy_dashboard.py`、自检 `scripts/test_render_vix_spy.cjs`。
- 方法：事件研究（非策略回测）。事件=任意 VIX 收盘<15（<13/<12 辅助）；前瞻=事件日收盘买入→持有 N 交易日收盘卖出，交易日对齐；对照=**非低位日互斥组**（Welch t）。独立样本另用区间起点。
- 关键结论：
  - **低位持续**：VIX<15 共 178 段，中位仅 3 天、均值 13.5、P90=32、最长 192 天（1994-12 起）；占全期 30.1% 交易日。自我强化：已持续 10 天再维持 ≥10 天概率 65.3%。
  - **高位回归**：从 <15 到 VIX 首破 20 中位 57 交易日（≈3 个月）。
  - **SPY 表现**：短持有 T+5/10 **低位日略弱于非低位日**（diff −0.10/−0.15pp，t≈−2）；T+20/60 无显著差异（−0.15pp~−0.17pp，t≥−1.65 不显著）；**T+120 低位日显著更强**（VIX<15 均值 5.31% vs 4.51%，+0.80pp t=3.9；VIX<12 +1.47pp t=6.2）。阈值越低长持越优。风险在低波动结束（VIX 重返 20 途中）而非低波动本身。
- 坑：① 显著性初版拿「事件=基线子集 vs 全集」做检验，t 虚高到 31——**必须用互斥对照（低位日 vs 非低位日）**；② ECharts CDN 异步加载 vs 模板 script 重插顺序，custom_html 初始化脚本必须加 echarts 就绪轮询，否则无头下 canvas=0 且无报错。
- 一致性：与旧 GSPC 口径（区间中位 3/均值 13.7、回归 60 天、T20 胜率 67%）交叉吻合，SPY 结果可信。
- README 第 6 类已加条目；git 本地 commit（`2026-08-26  msg: VIX低位SPY事件研究`）。

## 报告36：蓝筹周线「0轴上方高位刚死叉 × 回踩EMA20(1~3%缓冲)」事件研究（08-26 用户要求，承接报告33深化）
- **用户信号定义**：周线0轴上方（DIF&DEA>0）+ 高位死叉当周（Hist本周<0且上周≥0）+ EMA多头未破坏（EMA10>EMA20）+ 已跌破EMA10但收于EMA20上方1%~3%缓冲 + DIF较近26周峰值回落≥25% + 距上次DIF上穿0轴10~16周（首次动能衰竭）。问题=该背景下 EMA20 支撑有效性是否降低/只是破位率抬升。
- **实现**：scripts/macd_deadcross_ema20_backtest.py（周线级事件研究，读复权 data/<sym>/<sym>, W.csv，全部当周to-date递推无前视，DEA用逐点递归与ewm一致）+ scripts/build_macd_deadcross_dashboard.py（报告36_高位死叉回踩EMA20支撑/，事件明细独立选项卡）。分组 A=死叉+10~16周(n=14) / B=未死叉+10~16周(n=11) / C=死叉+窗口外(n=72)；破位=周收盘最低<事件周EMA20×0.98。
- **核心结论（反直觉 + 样本极小强警示）**：
  1. **支撑有效性未被削弱，破位率也未抬升**——A 破位率 **57.1% 反为三组最低**（B 72.7% / C 63.9%），刚死叉没有让 EMA20 更容易被打穿；
  2. A 组 T+20 +3.69%/61.5%、超额 −0.22pp，与随机周基线(+5.79%/64.1%)打平，支撑没有失效；
  3. **10~16周「首次回调」窗口是全部分档最弱段**（放宽后 +2.63% vs 16-24周 +7.07%/胜率77%、24-40周 +6.65%/75%）——用户假定的最佳窗口在数据上最差；
  4. **DIF回落≥25% 是主要样本杀手**：≥0/≥0.15 时死叉+窗口 n=37 / fwd20 +2.63%，提到 ≥0.25 骤减至 14 例 / +0.12%，≥0.35 仅 1 例——该阈值既杀样本又无收益提升；
  5. 窗口内死叉 vs 未死叉：+2.63% vs +4.11%（死叉收益略弱约 −1.5pp，但破位更低 57% vs 73%）；
  6. A 组破位(n=7) fwd20 −9.95% vs 未破位(n=6) +19.59% 分化极大，但破位组 fwd60 仍能收回 +8.1%（承接报告31 深死叉超跌反弹逻辑）。
- **统计警示**：A/B 样本 11~14 例，统计功效极低，t 值仅方向参考；C 组（窗口外）天然含更长牛市段，三组构成不同；事件最早 1980 年（早年 SPY 超额 NaN）。
- **敏感性体系**：ex-post 参数扫描已固化 stats.json 的 sensitivity 段（DIF回落 0/0.15/0.25/0.35、窗口 5-10/10-16/16-24/24-40 分档、窗口内死叉vs未死叉），dashboard 有「参数敏感性」ECharts 双图。
- 产物：scripts/macd_deadcross_ema20_backtest.py + scripts/build_macd_deadcross_dashboard.py + reports/36_高位死叉回踩EMA20支撑/{macd_deadcross_events.csv, macd_deadcross_stats.json, index.html}；README「突破与支撑」已同步一句结论；git 本地 commit。
