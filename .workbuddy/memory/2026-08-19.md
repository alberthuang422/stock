# 2026-08-19

## IPP 板块 8/18 大跌归因
用户问"昨天 ipp 为什么跌这么多"，确认 IPP = 独立电力生产商（Independent Power Producers）板块（美股无 IPP 代码；结合 8/18 行情与用户长期跟踪的 CEG/VST/UTES/XLU）。

### 拉数与新踩坑
- **数据补拉**：tln/nrg/ceg/vst/xlu/utes/spy 从 8/14 更新到 8/18。脚本 scripts/fetch_ipp_power_cdp.cjs（原生 CDP：PUT /json/new + Page.navigate + Runtime.evaluate，Node 22 内置 WebSocket）。
- **新坑 1**：sandbox Bash 内 `&` 后台启动的 Chrome 在 shell 退出时被回收，9222 端口随之失效。解决：必须用 `run_in_background=true` 启动 Chrome 作为独立任务；后续拉数脚本也用 `dangerouslyDisableSandbox=true`（沙箱连不上 localhost）。
- **新坑 2**：playwright `connectOverCDP` 后调 `browser.newPage()` 报 `Browser.setDownloadBehavior: Browser context management is not supported`（即使已有 about:blank 页）；改用 `browser.contexts()[0].newPage()` 仍失败。**最终绕开 playwright 高层 API，改手写原生 CDP（WebSocket + Runtime.evaluate），稳定可复用。**
- **新坑 3**：Chrome 新版 `PUT /json/new?url=...` 忽略 url 参数（停在 about:blank），必须先 PUT /json/new 建 tab 再 `Page.navigate`。原有 fetch_yahoo_cdp.cjs 模板未处理此变更，playwright 模式能 work 是因为 goto() 内部处理。
- **DGS30**：FRED `https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS30` 仍然直连可达；拉到 1977-2026/8/17。8/14 5.25% → 8/17 5.31%（FRED 收盘口径），8/18 盘中 5.32-5.33%（新闻）。

### 核心发现
- **8/18 当日**：TLN −11.0%（量比 3.1x）、NRG −5.6%、CEG −4.1%、VST −3.8%；XLU 仅 −0.36%、SPY −0.68%。板块等权 −6.12%，超额 SPY −5.44pp。
- **β 分解**（60 日 vs SPY，板块 1.22）：β 只能解释 −0.82%，**残差 −5.29pp = 板块级再定价**（叙事挤兑，非大盘拖累）。个股残差：TLN −9.7pp / NRG −5.1pp / CEG −3.4pp / VST −3.0pp。
- **三层归因**：① 30Y 美债收益率 5.32%+（2007 来最高）→ 长久期高估值集体杀估值；② AI 电力叙事集体撤退（XLU 横盘 vs IPP 普跌 = 不是公用事业板块，是 IPP 主题）；③ TLN 公司级叠加（8/5 财报后 RJ 463→449、OpCo 440→400 + $9.84 亿 shelf + 至少 1 家降级 Hold）。
- **罕见度**（2025 以来分位，越小越极端）：TLN 0.7% / NRG 3.7% / CEG 8.1% / VST 10.3%。
- **大背景**：板块 2025-09~10 见顶，距 52 周高 NRG −37% / VST −36% / CEG −34% / TLN −29%；2026 年内最大回撤 NRG −37.2% / CEG −35.4% / TLN −27.8% / VST −25.2%——**8/18 是已运行一年的回调中又一次加速**，不是新趋势起点。
- **8/17 已先行走弱**：TLN −1.6% / NRG −3.1% / CEG −1.5% / VST −1.4% — 典型"预期松动 → 催化落地"两段式。
