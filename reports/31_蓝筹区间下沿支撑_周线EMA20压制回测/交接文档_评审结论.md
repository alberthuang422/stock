## 0. 交接摘要（30 秒版）

**报告做了什么事**：47 只低波动蓝筹、1963–2026 共 1570 个「震荡区间触下沿」事件，按周线状态分三组对照——A（周线收 MA20 下方+未死叉）、B（周线在 MA20 上方，无压制）、C（周线在 MA20 下方+已死叉），度量事件后 T+5/10/20/60 交易日收益、胜率、破位率、尾部。

**报告原结论**：①死叉显著放大尾部风险（C 组 P10 = −10.7% vs A 组 −6.7%）；②压制本身影响有限（A vs B T+20 均值 1.67% vs 1.90%，t = −0.50 不显著）。

**评审结论（本轮交付的核心）**：方向正确，但「影响有限」表述有误导。

- 压制不是没代价——**代价在破位率而非胜率**（A 组破位率 62.8% vs B 组 56.3%），胜率对尾部亏损天然不敏感；
- **B 组胜率最高（65.6%）是牛市环境假象**，控制市场环境后 A 组胜率反超（震荡档 68% vs 63%）；
- **C 组"差"主要是环境混入**（死叉事件天然挤在下跌市），深跌档下 C 组超额反超 A 组；
- **死叉组内部两极分化：深死叉（EMA20/EMA50 < −5%）= 深熊超跌反弹（T+60 +7.08%），浅死叉（−2~−1%）= 下跌中继（T+20 −0.02%）**，不能一律回避。

**一句话给操作**：A 组可用（对随机买入有 ~+0.5pp/20 日超额）；浅死叉回避；深死叉可利用但须承受 80%+ 破位率与高颠簸；深跌环境下 C 组性价比反而高于 A。

## 3. 原报告结论（交付版本）

1. **死叉显著放大尾部风险**：C 组 P10 = −10.7% vs A 组 −6.7%，T+20 破位率 71.4% vs 62.8%，回撤 7.9% vs 6.0%；
2. **压制本身影响有限**：T+20 均值 A vs B 差异不显著（t = −0.50）；
3. T=5 短期 A 组显著领先（t = 2.09/2.25）。

## 4. 评审四段式（2026-08-25）

### 4.1 前提/背景校验 —— ✅ 干净
- A/C 组死叉间距分离干净（A 组最小 spread = +0.003%，C 组全部 <0），无「贴死叉边界」混入；
- 压制深度真实（A 组中位 −2.38%，最深 −24.7%），非擦边；
- 触达质量：78% 的 A 组事件收盘真实低于下沿（中位溢价 −0.34%）；
- 无前视；复权口径一致。

### 4.2 关键数据 —— 结论成立，但解释需换框架
- 换**超额口径**（个股 − SPY 同期）后排序反转：T+20 超额 A +0.24 / B +0.32 / C +0.47；T+60 C +1.83 > A +0.96 > B +0.88。C 组绝对收益"垫底"主要是**熊市环境拖累**；
- 环境证据：事件日 SPY 前20日均值 A −1.54% vs B −0.07% vs C −2.29%——B 组天然多在牛市触发；
- 控制环境后（震荡档 −1~+1%）：A 胜率 68% 反超 B 63%，B 的优势消失；
- 同股随机日对照（n=1570，排除事件日）：随机日均值 +1.13% / 胜率 57.1%；A 组 1.67 / 62.8、B 1.90 / 65.6、C 1.10 / 53.5——**A/B 有真实 alpha（约 +0.5pp/20日），C 组 alpha ≈ 0 且破位 71%**。

### 4.3 客观分析 —— 反直觉点
- **压制深度与收益非线性**：A 组压制 <−5% 档 T+20 均值 +2.21%（深蹲起跳），−2.5~−1% 浅压制档 +1.96%——浅压制（刚破位）才是下降趋势中继；
- 破位率 62.8% ≠ 支撑失效：破位后 60 日内多数能收回，A 组均值仍为正；
- 事件聚集：16% 事件发生在同日 ≥3 股（2022-09-23 / 2018-12-17 等系统性大跌日），t 值应视为上限（报告局限栏已提同类聚集，但未量化）。

### 4.4 结论与置信度 —— 高
- «压制无效»的说法不成立：压制组的成本是破位率抬升（≥+6pp，C 组使尾部更差），不是胜率下降——胜率天然对尾部不敏感；
- «B 组最优»不成立：是环境假象，控制环境后 A 反超；
- 置信度高（方向与数值均经复核）。

## 5. 用户原疑的直接回答

> 「价格在周线 EMA20 以下、碰到支撑位，胜率居然没下降？是不是条件设置有误？」

**条件设置没错，「胜率不降」是真实的**。三层解释：

1. **压制组的成本不体现在胜率上**——A 组胜率 62.8% 持平 B 组 65.6%，但破位率 62.8% vs 56.3% 高 6.5pp、P10 尾部差 1.8pp。支撑位「碰到就反弹」的概率没变，变了的是「碰到后扛不扛得住」；
2. **胜率对尾部损失不敏感**——跌破 2% 和跌破 20% 都算一次亏损，死叉组的尾部恶化（P10 −10.7%）不会被胜率捕获；
3. **B 组 65.6% 是牛市环境假象**——B 组事件多发生在市场平稳/上行期，控制环境后 A 组胜率 68% 反而更高。

真正该改的结论是「压制本身影响有限」——应为「压制不影响胜率与均值，但系统性抬升破位率」。

## 6. 本轮新增关键发现（二轮下钻）

### 6.1 死叉的内部结构（最有操作价值）
| 死叉深度（EMA20/EMA50−1） | n | T+20均值 | 胜率 | 破位率 | T+60均值 |
|---|---|---|---|---|---|
| 深死叉 <−5% | 118 | +1.54% | 57.6% | 83.1% | **+7.08%** |
| −5~−2% | 108 | +1.68% | 52.8% | 69.4% | +4.10% |
| **浅死叉 −2~−1%** | 74 | **−0.02%** | 50.0% | 62.2% | +2.90% |
| −1~0% | 102 | +0.78% | 52.0% | 66.7% | +3.29% |

- **深死叉 = 深熊超跌反弹**：弹性最大，同深跌档下 C 组 T+60 超额 +4.20% vs A +0.88%，但破位率高至 90%+（极度颠簸）；
- **浅死叉 = 下跌中继，真正的坑**（T+20 均值 −0.02%）；
- 均值 1.10% vs 中位 0.78% 的差距正是深档反弹拉出来的。

### 6.2 环境分层（A vs C，同档对比）
| 环境（SPY前20日） | A 绝对/超额/破位 | C 绝对/超额/破位 |
|---|---|---|
| 深跌 <−5% | +2.21 / −0.18 / 68% | +2.38 / **+1.46** / 78% |
| 回调 −5~−1% | +1.84 / +0.15 / 66% | +0.42 / −0.06 / 78% |
| 震荡 −1~+1% | +2.03 / +0.78 / 56% | +0.23 / −0.29 / 67% |
| 上行 >+1% | +0.59 / +0.29 / 64% | +1.24 / +0.52 / 66% |

破位率 C 全面高于 A（+2~12pp）→ 死叉最硬的代价 = 支撑可靠性。收益端 C 只在回调/震荡档劣于 A，深跌、上行档反超。

## 7. 对原报告的修改建议（若重交付）

按性价比排序：

1. **加超额口径图**：三组「个股 − SPY」收益曲线（T=5/10/20/60），这是排序反转、最颠覆直觉的一张图；
2. **加环境分层表**：A/B/C × 市场环境档（深跌/回调/震荡/上行）的均值/胜率/破位率二维表——能把「B 组牛市假象」和「C 组环境拖累」一次讲清；
3. **C 组加死叉深度分层**：深/浅死叉分桶表（6.1），把「回避 C」细化为「回避浅死叉、深死叉可利用」；
4. **结论措辞修正**：「压制本身影响有限」→「压制不影响胜率与均值，但系统性抬升破位率（T+20 +6.5pp）；已死叉在压制之上再叠尾部放大（P10 −10.7%、破位 71%）」；
5. **补随机日基线**：报告内加一行「同股票随机日 fwd20：+1.13%/57.1%」，让 A/B/C 的胜率有参照系。
