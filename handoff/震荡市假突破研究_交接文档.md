## 1. 研究目标（一句话）

**检验并量化：当大盘处于震荡（无趋势）状态时，个股的"假突破"是否更多、更深，以及"震荡市反向 fade 突破"作为交易策略是否可行。**

最终交付物：
1. 事件明细数据表（每个突破事件一行，CSV）；
2. 汇总统计 + 图表（HTML 报告）；
3. 策略级回测结果（fade 交易的逐笔盈亏明细 + 汇总）。

## 2. 背景与已完成的先导工作（重要，避免重复踩坑）

本研究的前身报告（内部编号 70）已完成第一版回测，其结论和**教训**直接决定本文档的设计：

**已有事实（4938 个突破事件，2010–2026，美股蓝筹+热门股）：**

| 假突破定义（向上突破，T+10 内跌回突破位的深度） | 震荡市 | 趋势日 |
|---|---|---|
| 触回（碰一下就算） | 54.8% | 45.1% |
| ≥0.5×个股日波动(ADR) | 32.4% | 27.5% |
| ≥1.0×ADR | 20.7% | 15.5% |
| ≥1.5×ADR | 13.0% | 9.9% |

**四条关键教训（本方案的全部设计都源于此）：**

1. **"假突破"不是一个是/否问题，而是一条严重度阶梯。** 温和回归（0~1×ADR）占大头、深度反转（≥1.5×ADR）是小尾巴。任何"假突破率 XX%"的单点结论都必须说明切在阶梯的哪一格，否则没有意义。→ 本方案**全程报阶梯，不报单点**。
2. **震荡条件对"率"的区分度天然有限（各档只差 3~10 个百分点），真正的强信号在收益维度**（震荡市突破后 T+20 收益中位 +1.2% vs 趋势日 +3.9%）。→ 本方案的终点是**策略回测**，不是统计率。
3. **旧震荡定义覆盖率 72% 太宽**，把大量准趋势日混进震荡组，稀释了对比度。→ 本方案要求把覆盖率压到 **30–45%**。
4. **旧事件提取层粗糙**：上/下事件 1:5 严重不对称、拐点确认时点偏早、未剔除财报事件。→ 本方案换成无拐点依赖的 Donchian 口径（主），并剔除财报。

## 3. 核心定义（精确、可复现，禁止自由发挥）

### 3.1 市场震荡状态（对 SPY 日线逐日计算，输出 0/1 序列）

三个支柱**独立计算**，**三选二命中 = 当日震荡**：

| 支柱 | 指标 | 震荡条件 |
|---|---|---|
| A 趋势强度 | ADX(14)（Wilder 平滑） | ADX < 20 |
| B 波动压缩 | 布林带宽 = (上轨−下轨)/中轨，BB(20, 2) | 处于过去 250 个交易日带宽的 <30% 分位 |
| C 区间结构 | 20 日累计收益 + 均线缠绕 | \|20 日累计收益\| < 2% 且 20 日内收盘价 ≥4 次穿越 20 日均线 |

- 每个支柱留一个**备用定义**（稳健性检验时替换）：A 备 = Kaufman 效率比 ER(20) < 0.2；B 备 = 20 日已实现波动率 < 250 日 30% 分位；C 备 = 60 日对数价格线性回归斜率不显著（p>0.1）且 R² < 0.1。
- **验收红线**：主口径下，震荡日占全部交易日的比例必须落在 **30%–45%**。超出此区间先调支柱 C 的阈值（±），不允许放宽到 50% 以上。
- 对 2015/2018/2020/2022 四个已知时期人工抽查震荡窗口起止是否合理（附抽查记录）。

### 3.2 突破事件（三口径并行，C 为主）

| 口径 | 定义 | 角色 |
|---|---|---|
| A 波段高点 | 收盘 > 前一已确认 ZigZag(5%) 波段高点 | 与旧报告衔接，可选 |
| B 横盘箱体 | 个股过去 20–60 日处于箱体（高低价宽度 ≤ 2×ATR(14)），收盘冲出箱体 = 突破 | 专题口径 |
| **C 55 日新高（主口径）** | **当日收盘价 > 过去 55 个交易日最高收盘价，且前一日不满足** | 主分析全部用它 |

三口径通用规则：
- **确认一律用收盘价**，盘中刺破不算；
- **毛刺过滤**：收盘价超出参考位 **≥0.3×ATR(14)** 才记为有效突破；
- **冷却期**：同一只股票同方向两次突破间隔 ≥20 个交易日；
- 向上/向下**完全对称**地提取，全程分开统计，禁止合并；
- **剔除**：财报发布日 ±1 个交易日内的突破（财报日历用 NasdaqTrader 或 EarningsWhispers 的免费日历即可）；拆股/单日涨跌 >40% 的跳变日（未复权数据的拆股伪影）；跳空开盘直接越过参考位 >2×ATR 的事件单独打标 `gap_skip`，不计入主统计。

### 3.3 假突破标注（ADR 归一化，全文统一）

- 对每次突破，记录 T+10（10 个交易日）内价格相对突破参考位的**最大反向偏离 `dev_max`**：
  - 向上突破：`dev_max = max_j (ref − close_j) / ref`；向下破位：方向镜像。
  - 归一化：`dev_adr = dev_max / ADR(20)%`，ADR 用**突破日当天及之前**数据计算。
- **阶梯报告**：P(dev_adr ≥ k)，k ∈ {0, 0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0}，分 震荡/趋势 × 上/下 四组。这是本研究的主图。
- 任何需要二值结论的场合，默认阈值用 **1.0×ADR**（兼顾样本量与严肃性），并同时给 0.5× 与 1.5×。

### 3.4 数据与样本

- 复权价（分红拆股调整，adj_close），**禁止名义价格**；
- 股票池：美股蓝筹 73 只（清单见附件 `blue_chips.csv`，也可直接用标普 100 成分），区间 2010-01-01 起；
- 流动性过滤：突破日 20 日日均成交额 > 1000 万美元；
- 基准：SPY 日线（市场状态）+ 个股所属板块 ETF（控制变量用，可选）。

## 4. 统计分析设计

1. **主对照**：四组（震荡×上下、趋势×上下）阶梯曲线 + 每档率差 + 95% CI。
2. **显著性**：2×2 卡方 / Fisher 精确检验（默认阈值 1.0×ADR）；**按"震荡期"聚类的稳健标准误**（同一震荡期内多股同时突破不独立，不处理会虚高显著性）；或 60 日 block bootstrap。
3. **控制回归**：logistic，因变量 = 是否假突破（≥1.0×ADR），自变量 = 震荡 + 市值 + beta + 突破幅度(×ATR) + 当日量能比 + 板块固定效应。
4. **分时期稳健性**：2010–15 / 2016–19 / 2020–21 / 2022–26 四段分别跑；多分层统一 BH 校正。
5. **策略回测（本研究的终点，详见 5.6）**。

## 5. 实施步骤（7 步，按顺序执行，每步有明确产出与验收）

### Step 0 · 环境与数据准备
- Python ≥3.10，pandas/numpy/scipy；TA-Lib 可选（ADX/ATR 手写也不难，见 8.1）。
- 数据源任选其一并固定：yfinance（注意必须显式 period1/period2，range=max 是月度采样假数据）/ Stooq / Polygon。
- **验收**：随机抽 5 只股票与官方行情核对 3 个日期收盘价，误差 <0.1%。

### Step 1 · 震荡判定器
- 输入 SPY 日线 → 输出 `date, pA, pB, pC, choppy(0/1)` CSV + 一张震荡窗口叠加在 SPY 走势上的着色图。
- **验收**：覆盖率 30–45%；四段已知时期人工抽查通过。

### Step 2 · 突破事件提取（先只做口径 C）
- 输出事件表：`ticker, date, dir, ref, close, atr, dev_max, dev_adr, gap_skip, earnings_flag, choppy`。
- **验收**：事件数量级合理（73 只 × 16 年，向上事件应在数百到一千余例）；上/下事件数比例在 1:2 以内（若 1:5 以上说明实现有 bug）；随机抽 20 个事件对照 K 线图人工核对。

### Step 3 · 阶梯与主对照
- 生成四组阶梯表 + 图 + 卡方/聚类稳健 SE。
- **验收**：与先导研究同口径数值可对照（触回档应在 45–55% 量级，1.5× 档应在 10–15% 量级），数量级不符先查 bug 再下结论。

### Step 4 · 稳健性
- 换震荡备用定义重跑 Step 1–3；T+5 / T+20 窗口各跑一遍；四段分时期。
- **验收**：核心结论（震荡组各档高于趋势组）在所有变体下方向一致，否则报告必须如实写明"不稳健"。

### Step 5 · 控制回归
- logistic 回归，报告震荡项系数、OR 值、95% CI。

### Step 6 · 策略回测（fade 假突破）
- 规则：**入场** = 突破后 T+5 内收盘价回踩突破位（dev_adr > 0）时反向入场（向上突破→做空）；**止损** = 价格重新站上突破位 +0.5×ATR；**目标** = 突破位 −1.5×ATR（向下镜像）；**时限** = T+20 强制平仓。
- 逐笔记录：入场/出场价、持有天数、盈亏（以 ATR 和 % 双单位）、是否止损。
- 分 震荡/趋势 两组对比：胜率、盈亏比、期望值、最大回撤。
- **验收**：全部逐笔明细可导出 CSV；随机抽 10 笔人工核对入场/出场价。
- **如实标注局限**：未含做空成本（融券费率）与滑点；样本内外未切分（如做参数调优，必须留 2022 后做样本外验证）。

### Step 7 · 报告
- 单文件 HTML：①方法与口径 ②震荡判定验证图 ③阶梯主图 ④统计检验 ⑤策略回测（净值曲线 + 逐笔明细表）⑥局限与证伪点。

## 8. 已知坑与注意事项（按踩坑概率排序）

### 8.1 指标实现细节（最容易错）
- **ADX 必须用 Wilder 平滑**（ewm alpha=1/14），用 SMA 代替会系统性偏高，导致震荡日偏少；
- **ATR 的 TR 必须含跳空项**：`TR = max(high−low, |high−prev_close|, |low−prev_close|)`，只用 high−low 会低估 10–20%；
- 布林带宽分位用**过去 250 日滚动窗口**计算，禁止用全样本分位（未来函数）；
- ADR(20) 用**突破日前一日为止**的数据，含当日会轻微泄漏。

### 8.2 前视偏差（研究作废的第一大原因）
- 震荡标签、ATR、分位数——**所有特征只允许用 ≤ 突破日（或前一日）的数据**；
- 自检方法：把全部数据截断到某个中间日期重跑，截断点之前的所有标签/事件必须**逐位一致**；不一致即有泄漏。
- 典型泄漏点：rolling 窗口忘了 shift、全样本归一化、用"已确认拐点"时确认时刻早于实际确认条件达成时刻（旧报告就踩过：pivot 确认需要价格反向走满阈值才算确认，不能 pivot 后 2 根 K 线就当已知）。

### 8.3 事件层陷阱
- **拆股伪影**：未复权数据里拆股日像单日暴跌 50%，会被误判为"向下破位"。用复权价 + 剔除单日 |涨跌|>40% 的日期双保险；
- **财报污染**：财报跳空突破在震荡市里反而更可能是真突破，不剔除会稀释震荡组假突破率（旧报告实测踩过）；
- **簇状重复**：一段慢牛里价格贴着 55 日新高走会天天触发——20 日冷却期必须实现，且"前一日已处于突破态"的日期不能再记为新事件；
- **上下不对称**：美股上涨市向下破位事件天然多于向上突破，两组样本量差 3–5 倍是正常的（旧报告 615 vs 3150），分开报告即可，不要强行平衡；
- **幸存者偏差**：用当前成分股回看历史会高估结论。一期用蓝筹池可接受，但报告中必须写明此局限；二期如扩到全市场需用历史成分股。

### 8.4 统计陷阱
- **聚类问题**：同一震荡期内几十只股票一起突破，事件不独立。直接用普通卡方会把 p 值压得过小——必须按震荡期聚类或 block bootstrap；
- **多重检验**：阶梯 8 档 × 3 口径 × 4 时段会产生几十上百个 p 值，统一做 BH 校正，报告中只引用校正后仍显著的结果；
- **"率差小但收益差大"是常态**：率维度只差 3–10pp 不代表没有交易价值，反之亦然——结论分开下，禁止互相替代。

### 8.5 策略回测陷阱
- fade 做空方向：止损距离（0.5×ATR 重新站上突破位）天然小于目标距离（1.5×ATR），**胜率必须 >33% 才有正期望**，回测时先验证这一不等式再谈优化；
- 震荡窗口**首尾各 5 日**是模糊带（状态将变未变），建议单独标记，不进主统计；
- 大选/中期选举等特殊窗口（旧报告实测：中期选举前 2 月突破后 T+20 中位 −4.3%，是"突破坟场"）建议做分层，不要平均掉。

### 8.6 工程与沟通
- 参数全部集中在 `config`（阈值、窗口、乘数），报告里每个数字都能追溯到参数值；
- 中途任何口径调整**只改 config 不改代码逻辑**，并重跑全链条；
- 每个 Step 完成后先给委托方看该步验收产出，再继续下一步（短反馈循环，避免做完发现方向错了）。

## 9. 预期结果与判读指南（防止过度解读）

基于先导研究，**合理预期**是：

- 震荡组阶梯全程高于趋势组 3–10pp，收窄震荡定义后差距有望扩大到 10pp 以上；
- 深度档（≥1.5×ADR）假突破占比 10–20%——**这意味着 fade 策略的交易信号不会多**，73 只股票一年大约几十次，属低频策略；
- fade 策略的盈利主要来自少数深度回归事件，期望值厚不厚取决于止损纪律，**不要指望胜率漂亮**（预计 40–55%）；
- 若最终结果震荡-趋势差异在收窄定义后仍 <5pp，则如实结论"大盘震荡状态对个股假突破的区分度弱，该因子单独不足以构成策略"，这也是有价值的研究结论。

**证伪点**（出现以下情况说明实现有误，停下来检查）：
- 触回档（k=0）假突破率 <30% 或 >70%；
- 阶梯曲线不单调递减；
- 震荡覆盖率 <20% 或 >50%；
- 策略回测净值曲线与逐笔明细加总对不上。
