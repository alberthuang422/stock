## 一、研究问题

**场景**：原油大涨带动月差走扩 → 价格回落到起涨前价位 → 月差没有同步回落（挂在高位）。

**问题**：这种"价格 round-trip、月差净走扩"的状态出现后，月差后续是**补跌收敛**还是**继续走扩**？

**两种结论的交易含义相反**：
- 显著收敛 → 做空月差的均值回归信号（价格回来了，月差迟早补跌）；
- 反而走扩 → "月差硬"是现货真紧的确认信号，价格回落只是噪音。

**核心语义**（x = 近月 m，y = m − n）：价格 round-trip 净变化 ≈ 0 而月差净走扩，等价于**远月 n 在本轮 round-trip 中净下跌**——"价格白涨白跌一圈，远月被永久性压低一个台阶"。

## 二、事件定义（核心）

### 2.1 触发规则（水平版，用户定稿）

```
参考位：x1 = 回看窗口 L 内的价格谷底，y1 = 谷底附近 3 bar 月差中位数
大涨：  峰值 − x1 ≥ θ（θ 口径见 §2.3）
回到：  x2 ≤ x1（价格跌回起涨位，严格不等式，用户定稿）
挂高：  y2 − y1 ≥ δ（月差增量地板，滤 1-tick 噪音）
确认：  回落首次触发后，滚动 5 bar 内 ≥3 bar 满足（x2 ≤ x1 且 y2 − y1 ≥ δ）
        → 事件成立，参考位冻结，进入前向观察 T+N
冷却：  触发后 N bar 内状态机重置，不检测新事件（N = 前向窗口长度）
```

### 2.2 实现：单遍状态机 O(n)，无嵌套循环、无 β、零前视

```python
trough_idx, trough, peak = 0, price[0], price[0]   # 候选 x1 与峰
confirm = deque(maxlen=5)

for t in range(n):
    p, s = price[t], spread[t]
    if cooling: cooling -= 1; continue

    # ① round-trip 判定（先判事件、后更新谷底，顺序不能反）
    if p <= trough and peak - trough >= theta(trough, peak):
        y1 = median(spread[max(0,trough_idx-1) : trough_idx+2])
        confirm.append(s - y1 >= delta(y1))
        if sum(confirm) >= 3:
            fire_event(t, ref=(trough_idx, trough, y1, peak))
            cooling = N; reset_state()        # 冷却后从冷却点重新初始化
            continue
    else:
        confirm.clear()                        # 离开回落状态 → 计票清零

    # ② 谷底/峰更新
    if p < trough: trough, trough_idx, peak = p, t, p
    elif p > peak: peak = p
```

**无前视论证**：trough/peak 在 t 时刻均为已实现信息；trough_idx+1 的数据在事件判定时已存在（谷底早于峰、峰早于回落）；"回到 x1"本身是事后可观测的确认条件——先前讨论的波段高点确认延迟问题在此定义下自动消失。

**边界语义（已定稿）**：
1. 确认期内创新低 → 参考位**冻结**（x2 ≤ x1 仍成立；新低自然成为下一轮候选谷底）；
2. 回落状态中断（价格重新走高出峰）→ 计票清零、谷底峰继续正常跟踪；
3. trough / 触发点 / 前向窗口任一端落在 LTD±3 脏区 → 事件作废。

### 2.3 参数表

| 参数 | 含义 | 主口径 | 稳健性 | 备注 |
|---|---|---|---|---|
| L | 回看窗口 | 24 bar（≈1 交易日） | 16 / 48 | 找谷底的范围 |
| θ | 大涨阈值 | 峰−谷 ≥ 1.0 × ATR(24 bar) | 0.7 / 1.5 ×ATR | ATR 口径跨品种 scale-free；对照版 CL 1.5% / HO·RB 2.0% |
| δ | 月差增量地板 | y2−y1 ≥ 0.25 × mean\|Δy\|(24 bar) | 0.1 / 0.5× | 滤 tick 噪音 |
| 确认 | 持续性 | 5 bar 内 ≥3 bar | 4/5、3/7 | 用户定稿 3/5 |
| N | 前向窗口 = 冷却期 | 8 bar（8h） | 4 / 16 / 24 | 多窗口全报 |

**调参纪律**：θ/δ 先按上表拍 → 跑出触发频率与基准率（§5）→ 若事件 <50 个再放宽 θ 重跑；**参数一经选定不再改**，避免数据挖掘。参数在前 70% 时间样本上定，后 30% 做样本外验证。

## 四、样本构造规则

1. **分 pair 独立分析，不拼接**：同一合约对的月差是真实报价、天然连续；拼接序列水平失真，无法做"深 back vs contango"分组；
2. **脏区剔除**：任一合约 LTD 前 3 日 ~ LTD 后 1 日的 bar 不参与事件（含事件参考位、触发点、前向窗口任一端）→ 年折损 19%；
3. **冷启动**：滚动 min/max/ATR 只需 ≤24 bar，冷启动损失 <1 天/pair，可忽略（60m 下已重新核算）；
4. **冷却期 = N**：保证事件样本前向窗口互不重叠（观测独立）；稳健性用全样本 + Newey-West / block bootstrap 重叠校正；
5. **跨品种同时触发不合并样本**：CL/HO/RB 同日事件高度相关（同一原油行情驱动），分品种报数 + 提供"按事件日聚类"的显著性检验；
6. **镜像事件**（价格 round-trip 下跌、月差净收窄）：平行记录不进主结论，用于对称性检验。

## 五、统计评估

### 5.1 对照组（事件研究的灵魂，非可选项）

| 组 | 定义 | 回答什么 |
|---|---|---|
| C0 无条件基准 | 全部干净 bar 的 Δy(N) 分布 | 3/5 模式随机下出现多频繁；触发样本是否真的异于常态 |
| C1 round-trip 对照 | 大涨+回落但**月差没挂高**（y2−y1 < δ）的 episode | 把"价格 round-trip"和"月差挂高"两个成分拆开——核心增量在 C1 与触发组之差 |

### 5.2 主统计量

- 触发后 Δy(N)（月差变化）与 **P(收敛)**（Δy(N) < 0 的比例，用户口径：收敛 = 月差回落）；
- 平均/中位收敛幅度、分位数（P10/P25/50/75/P90）；
- 触发组 vs C0 vs C1：均值差 + Mann-Whitney U + t 检验（显著性三档 sig/edge/no + p 值，沿用项目口径）；
- 按事件日聚类的稳健标准误（跨品种同日触发）。

### 5.3 分组拆解（防"均值假象"）

- 分品种（CL / HO / RB）；
- 分结构状态：y1 > 0（backwardation）vs y1 ≤ 0（contango 边缘）；
- 分事件强度：峰谷涨幅（ATR 倍数）分位；
- 分时段：亚盘 / 欧盘 / 美盘（ET 02:00–08:00 / 08:00–14:00 / 其余）。

## 七、风险与已知坑

1. **样本量风险（最大）**：数据仅 ~5 个月 × 3 品种。若事件 <50 个：先放宽 θ；仍不足则补更早月份合约（P1）；再不足则明确报告"样本不足，仅描述性结论"——**不硬凑显著性**；
2. **无 volume**：无法验证薄流动性时段，flat-bar 弱代理兜底；若导出可带 volume，优先补；
3. **x=m 与 y=m−n 的机械耦合**：信号语义 = 远月相对走弱，解读时必须用这个语义，不能说成抽象的"价差落后"；
4. **谷底检测对 L 敏感**：L 过短会把小波动当谷底（θ 兜底）、过长会错过参考位（稳健性窗口对照）；
5. **单一数据源**：所有 pair 两腿必须同源；重导文件与已落盘 3 文件格式一致性需 ingest 脚本校验（行数、时间戳连续性、OHLC 自洽）。
